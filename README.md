# 💬 Chatting Application

## 🌐 Live Demo

[Open Chatting Application](https://chatting-application-ruby.vercel.app/)

A simple and responsive chatting application built using **HTML, CSS and JavaScript**.

## 🚀 Features

- 💬 Send messages
- 🗑️ Delete messages
- 🌙 Dark mode
- 🟢 Online status
- 💾 Messages stored in browser
- 📱 Responsive design
- ⌨️ Press Enter to send messages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Enter your name.
5. Type a message and click **Send**.
